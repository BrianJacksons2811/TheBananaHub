FAQ

Common branding questions.

Do I get the logo in all formats?

Yes. You receive high-quality exports suitable for web and print. Vector files can be included on higher packages.

How many revisions do I get?

Each package includes revisions. Additional revisions can be added if needed.

What’s the difference between Branding and Graphic Design?

Branding defines your identity system. Graphic design creates individual marketing assets using that system.

Can you also build my website after branding?

Yes — branding + website build is a strong combo and makes the website much more consistent.
